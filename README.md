# ClipStar — idle-симулятор блогера

2D idle-игра на **Godot 4.3** в духе Lamar – Idle Vlogger: снимаешь ролики, копишь подписчиков,
прокачиваешь студию. Весь арт — собственные SVG, звук синтезируется кодом (внешних ассетов нет).

## Механики
- доход в секунду от апгрейдов (камера, свет, стол, монтаж), тап по студии даёт разовый доход;
- ролики тратят энергию (20, +1 за 45 сек) и приносят деньги и подписчиков;
- буст ×2 на 15 минут, копилка (10% дохода), 6 задач с наградами, уровень канала;
- 5 стадий студии по подписчикам: комната визуально перестраивается;
- офлайн-доход до 8 часов, сейв `user://save.json` (+`.bak`), время только UTC.

## Сборка
GitHub Actions: `.github/workflows/build-apk.yml` → Actions → build-apk → Run workflow →
artifact `ClipStar-apk`. Debug-подпись фиксированная (`ci/debug.keystore.b64`), поэтому
обновления ставятся поверх без удаления и без потери прогресса.

## Структура
- `scripts/autoload/` — Save (сейв), Game (экономика и прогресс), Sfx (синтез звука)
- `scripts/ui/main.gd` — весь HUD, панели, таб-бар
- `scripts/world/studio_view.gd` — сцена студии и персонаж с эмоциями
- `assets/art/` — SVG (комнаты 5 стадий, персонаж, иконки)
