# ClipStar — Godot 4.3, шаг 3: визуал, «сок», UI, 3 апгрейда, звук

Idle-симулятор блогера: Мира снимает ролики, получает просмотры, монеты и подписчиков,
прокачивает студию и зарабатывает, пока игрок офлайн. Godot 4.3, GDScript 2.0, GL Compatibility,
портрет, Android (com.clipstar.game). Без сети, плагинов, закрытых SDK и бинарных ассетов.

## Папки
- `project.godot` — главная сцена, автозагрузки (Save, Progress, Economy, Audio), портрет, GL Compatibility, тема UI.
- `export_presets.cfg` — пресет "Android" (debug, armeabi-v7a + arm64-v8a, без Gradle, JSON включены фильтром `*.json`).
- `assets/data/` — баланс: `balance.json`, `topics.json`, `upgrades.json` (камера, свет, стол).
- `assets/shaders/` — `toon` (3 тона + rim), `toon_outline` (обводка вторым проходом), `wall_gradient` (фон),
  `blob_shadow` (мягкая тень), `vignette`, `glow` (свечение монет), `flash` (вспышка камеры).
- `assets/materials/` — материалы на палитре из 8 цветов: `toon_*` (с обводкой), `toon_*_flat` (без обводки, для лица),
  `glow_*` (светящиеся), `outline`, `wall_gradient`, `blob_shadow`.
- `assets/icons/` — SVG-иконки (монета, сердце, лайк, молния, глаз, подписчик, звезда, апгрейды, звук).
- `assets/theme/ui_theme.tres` — тема UI: крупный шрифт с контуром, кнопки с «нажатием», панели.
- `scenes/main.tscn` — студия + съёмка + виньетка + слой UI.
- `scenes/studio/studio.tscn` — комната: ковёр, постеры, неон, полка с книгами, торшер, растение, кресло-мешок,
  стол с ноутбуком; уровни апгрейдов (телефон на коробке → штатив, кольцевая лампа, стол с техникой).
- `scenes/studio/mira.tscn` — Мира с лицом (глаза, зрачки, блики, брови, 3 формы рта, румянец) и AnimationPlayer:
  idle, talk, happy, surprised, dance, sad, wave.
- `scenes/ui/` — HUD и окна: выбор темы, итог ролика, апгрейды, офлайн-доход.
- `scripts/autoload/` — сервисы: сейв (user://save.json, sha256, .bak, UTC), прогресс, экономика, звук (SFX синтезируются кодом).
- `scripts/data/` — чтение JSON; `scripts/gameplay/` — формулы и цикл съёмки; `scripts/studio/` — студия, Мира, палитра;
  `scripts/fx/ui_fx.gd` — анимация кнопок, «поп», счётчики; `scripts/ui/` — HUD и окна, `main.gd` всё связывает.

## Что происходит при съёмке
Вспышка и щелчок затвора, тряска камеры, мигает REC, Мира говорит в камеру, летят сердечки, счётчик просмотров
тикает вверх, тапы «Фокус!» поднимают качество. В конце — вспышка, звук кассы, взрыв сердечек и лайков,
всплывающие «+N монет / +N подписчиков / +XP», реакция Миры (радость, танец при вирусном ролике, грусть при плохом кадре),
затем экран итога: просмотры заполняют полосу относительно рекорда канала, по очереди появляются монеты и подписчики, фанфары.

## Заметки
- Bloom окружения в GL Compatibility (Godot 4.3) не поддерживается — свечение монет сделано шейдером `glow`.
- В headless-режиме Godot пишет `mesh_get_surface_count: Parameter "m" is null` — это пустой рендер сервера, на устройстве этого нет.
- minSdk/targetSdk — из стандартного шаблона Godot 4.3 (21/34); свои значения задаются только при Gradle-сборке.
