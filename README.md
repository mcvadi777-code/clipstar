# ClipStar — Godot 4.3, вертикальный срез

Idle-симулятор блогера: Мира снимает ролики, получает просмотры, монеты и подписчиков,
улучшает камеру и зарабатывает, пока игрок офлайн. Godot 4.3, GDScript 2.0, рендер GL Compatibility,
портрет, Android (пакет com.clipstar.game). Без сети, плагинов и закрытых SDK.

## Папки
- `project.godot` — настройки: главная сцена, автозагрузки, портрет, GL Compatibility, ETC2/ASTC, тема UI.
- `export_presets.cfg` — пресет "Android" (debug, armeabi-v7a + arm64-v8a, без Gradle, json включены фильтром `*.json`).
- `assets/icon.svg` — иконка приложения и лаунчера.
- `assets/data/` — баланс в JSON: `balance.json` (энергия, формулы, офлайн), `topics.json` (темы роликов), `upgrades.json` (апгрейды; в срезе — камера). Правишь числа — игра подхватывает без изменения кода.
- `assets/theme/ui_theme.tres` — тема всех Control-узлов (кнопки, панели, полосы, размер шрифта), подключена в project.godot.
- `scenes/main.tscn` — главная сцена: студия + узел съёмки + слой UI.
- `scenes/studio/studio.tscn` — 3D-студия из примитивов: стена, стол, монитор, Мира, камера на штативе, лампа REC.
- `scenes/ui/` — HUD и окна: выбор темы, итог ролика, апгрейд, офлайн-доход.
- `scripts/autoload/` — сервисы-синглтоны: `Save` (user://save.json, sha256, .bak, UTC), `Progress` (подписчики, опыт, уровень, кулдауны), `Economy` (монеты, энергия, апгрейды, пассивный и офлайн-доход), `Audio` (звуки синтезируются в коде).
- `scripts/data/game_data.gd` — чтение и проверка JSON, значения по умолчанию при ошибке.
- `scripts/gameplay/formulas.gd` — все формулы и форматирование чисел; `video_shoot.gd` — цикл съёмки.
- `scripts/studio/studio.gd` — анимации студии; `scripts/ui/` — логика HUD и окон, `main.gd` всё связывает.

## Цикл среза
«Снять ролик» → выбор темы (закрытые по уровню и остывающие темы недоступны) → съёмка 4 с,
тапы по «Фокус!» поднимают качество → итог: просмотры, монеты, подписчики, опыт, шанс вирусности →
апгрейд камеры увеличивает охват и доход. Пассивный доход каждую секунду. При запуске — окно офлайн-дохода
(время по UTC, максимум 8 ч, 50% от пассивного).

## Заметки
- В headless-режиме Godot пишет `mesh_get_surface_count: Parameter "m" is null` — это особенность пустого
  рендера на сервере, на устройстве этого нет.
- minSdk/targetSdk берутся из стандартного шаблона Godot 4.3 (21/34): задать свои можно только при Gradle-сборке.
